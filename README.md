= Javascript Interactive Morse Code Tutor =

The goal of this project is to create an interactive [Morse Code](https://en.wikipedia.org/wiki/Morse_code) tutor to aid in the learning of how to decode Morse code.  

Lightly touched up by <rrw@semiramis.org.uk> to improve the UI and add a "select all the letters" toggle. The UI was auto-generated by Claude (which did quite a good job, I think).

Many thanks to https://github.com/amusselm/MorseCodeTutorJS !
